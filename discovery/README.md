# Discovery Directory

**UNTRUSTED. Contents may never be imported by `src/`, `checker/`, `proof/`, or `tests/`.**

Use this directory for:
- Exploratory numerical computations (floating-point, not certified)
- Heuristic experiments and parameter searches
- Scratch work that informs but does not constitute proof

Outputs that survive scrutiny must be promoted to `src/` with full interval arithmetic
certification before entering the proof chain.
