# Baseline References

This directory stores verified source documents for theorems admitted as `[BASE]`.

Before any `[BASE]` theorem is used in a proof, the exact theorem statement must be
verified from the source document stored here.

**Rule:** no theorem from a baseline source may be used without:
1. The PDF stored in this directory
2. An exact theorem number and statement verified from the PDF
3. A one-line entry in this table
