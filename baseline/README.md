# Baseline References

This directory stores verified theorem statements for results admitted as [BASE].

Before any [BASE] theorem is used in a proof, the exact statement must be verified
against the source stored here. "I remember what it says" is not a pass.

Rule: no [BASE] theorem may enter the proof chain without the PDF stored here,
an exact theorem number verified from the PDF, and a one-line entry in this table.
