# Witness — Partial-sum bound

No finite witness proves the universal partial-sum bound. The empirical
witness is the recomputed table of S(X) (floating-point A(n), generated by the test
in tests/test_partial_sum_bound.py) over the ACTUALLY verified range
X in [100, 5000], with maximum |S(X)|/sqrt(X) = 0.258953 at X = 196 and
the tested threshold 0.26. No claim is made for X beyond 5000; the
constant is discovery-tier. (Earlier drafts referenced
src/zero_free_arb.py and baseline/zero_free_scan.json; neither belongs to
this batch and the references are removed.)
