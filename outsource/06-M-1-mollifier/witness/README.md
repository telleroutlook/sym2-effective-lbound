# Witness — M-1

## Status

No numerical witness exists. The core analytic lemma (GL₃ shifted-convolution
sum for fixed Π) is at the research frontier.

## What would constitute a witness

1. Explicit computation of I(T) for specific Π and T values
2. Verification that I(T) ≥ c₀T for T ≥ T₀
3. Verification of the mollifier coefficients b_m
