# Witness — M-1 v2

## Status

No numerical witness exists. The core analytic lemma (mollified twisted GL₃
moment with power-saving error) is at the research frontier.

## What would constitute a witness

1. Explicit computation of I(T) = ∫_T^{2T} |M(½+it)L(½+it,Π)|² dt
   for specific Π, mollifier {b_m}, and T values
2. Verification that I(T)/T → C_{Π,θ} > 0 as T → ∞

## Note

The witness does NOT need to verify L(½,Π) > 0 — that was the wrong
bridge lemma from v1, now deleted. The mollified moment I(T) is a
statement about t-average behavior, not about the central value.
